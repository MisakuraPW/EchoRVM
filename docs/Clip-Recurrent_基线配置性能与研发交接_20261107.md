# Clip-Recurrent 基线说明书：配置、实测性能与研发交接

日期：2026-11-07。适用范围：EchoNet-Dynamic 的 Clip-Recurrent-Global patch8 / L16 / W64 / H0 开发基线。本文不要求读者先了解此前对话或排查过程；凡未测或不能单独归因的项目，均明确标出。

## 1. 交接结论

**后续分割以独立400轮 SSL + 恢复分割监督覆盖为主对照。** 这条路径在同一批 1276 个 TEST 病例、2552 个真实标注帧上得到 **93.0135% 全局 Dice、92.4633% 患者平均 Dice**；本地官方发布权重单帧锚点为 **92.9765%、92.3920%**。全局差 +0.0370 个百分点，现阶段可说接近，不应说已稳定超越。

**EF 要分清权重来源。** 独立400轮 SSL 的 EF 全量微调已有 VAL MAE **3.9252 pp**，尚未测该权重的 TEST。已完成的 EF TEST **3.9866 pp** 来自独立1600轮 SSL 的另一个 EF 微调权重。不要把 93.0135% 和 3.9866 pp 写成同一 SSL 权重、同一联合模型的两项成绩。本项目目前是共享预训练架构、按任务分别全量微调，不是一次联合训练输出分割和 EF。

开发可以收敛到两条线：**在数据、评估、权重起点固定的前提下改优化配方；在优化配方固定的前提下改模型结构。** 不必先重跑1600轮、重做无递归/无缓存对照、追论文原版 ROI 或反复纠结约93%的小数点。涉及论文“超越”时，再用配对协议及独立确认支持结论。

## 3. 数据、监督与取窗

### 3.1 数据口径

- 数据为 EchoNet-Dynamic，原生 `112×112`，灰度 `uint8` NPY，读取后到 `[0,1]` 浮点并在内存中重复三通道。无新增 RGB 磁盘缓存，不为适配 patch 而缩放原视频或轮廓。`FileList.csv` 提供拆分、视频元数据和 EF；`VolumeTracings.csv` 提供左室标注帧与轮廓，按原生坐标栅格化。
- SSL 用官方 TRAIN/VAL/TEST 三个拆分的**无标签影像**，共10030个实际训练视频；独立 SSL manifest 不读 EF 和轮廓标签。监督仅用 TRAIN 拟合、VAL 选权重，TEST 标签锁定到选权重之后。这是 **transductive all-split unlabeled SSL**，不能写成“预训练从未见过 TEST 影像”。新方法和基线必须同样暴露；若要严格归纳式结论，另设仅 TRAIN 影像 SSL 或未见外部队列，不能混榜。
- FileList 的 TRAIN/VAL/TEST 数分别为 7465/1288/1277。可用分割标签是 TRAIN 7460例/14920帧、VAL 1288例/2576帧、TEST 1276例/2552帧。缺可用 trace 的视频不能补造 GT；“完整”指全部可用标注，不是强行让每个视频都有标注。分割、EF、SSL 的合格集不是同一集合。
- 下表 `观察数` 指模型前向预测次数，不是独立标注或患者数。病例键按数据清单的记录 ID 聚合，不把多窗口当独立病例。

### 3.2 各阶段的窗口

| 阶段 | 取样及历史 | 标签/筛选 |
| --- | --- | --- |
| SSL | 每 epoch 每视频随机一个窗口，起点由 seed / epoch / 视频确定；连续帧、stride 1；`T=min(64, floor(N/16)×16)`；没有额外前缀 `H=0` | 至少一个真实16帧clip，不为补齐短视频复制帧。每轮10030窗，记录640720帧次；不要解读为每轮看完每个视频所有帧 |
| 原分割训练 | 每个合格标注帧一条训练记录，target 在最后clip的48–63位置之间按 epoch 轮换；全窗64帧 | 同时要求全部16个目标位置可取，TRAIN 4975例/8108真实帧 |
| 恢复分割训练 | 旧合格帧仍用旧取窗；其余标注帧走下述变长边界规则 | TRAIN 7460例/14920真实帧；训练池连续确定性随机排列，遍历完才进入下一排列。每检查周期抽8108窗，不是固定丢掉剩余帧 |
| 分割选权重 VAL | 原共同集，目标位置48–63全部展开 | 902例、1478源帧、23648观察。保证原400与恢复版可比 |
| 完整分割 VAL / TEST | 原合格帧仍展开16位置，新增边界帧一次预测 | 完整VAL 24746观察，完整TEST 24557观察；完整VAL只补评，不反选checkpoint |
| EF 冻结及FT | 每视频一段真实连续64帧、无额外前缀，TRAIN 起点随 epoch 变化；VAL/TEST 固定 seed/epoch0 的单窗，不是取最后64帧，也不是五窗平均 | 有真实 EF 标签且能提供64帧。TRAIN 7427例，VAL 1279例，已测 TEST 1267例；未为 EF 应用分割变长补帧 |

**变长分割是窗口策略，不是把 ViT 的局部输入改成任意长度。** 设标注帧索引 `f` 从0开始，新增边界记录取 `T=min(64,max(16,ceil((f+1)/16)×16))`；窗口在 `f` 结束，负索引映射到该视频第0帧，目标索引恒为 `T-1`。例如 `f=20` 取32帧槽位，左补11槽；不是只有 `f<15` 才可能补帧。末尾无法支持16种位置的帧也可以用截至目标的64帧。输出记录 `coverage_kind` 和 `left_padding_frames`，标签始终只对应真实 `f`。按窗口长度分组进主干，不给短样本补成64帧。

新增边界记录不会访问目标后的帧；保留的旧16位置协议可能看到同一clip内的后续帧。**整体基线不是逐帧零等待的严格在线因果评测**。要比较流式候选，需明确报告时延与可见范围，并让 baseline 同协议重评，不能把旧离线成绩充当严格因果对照。

### 3.3 标准化与增强

主线所有模型用 `mean=(.485,.456,.406)`、`std=(.229,.224,.225)`，由模型做一次标准化；灰度复制不等于原始彩色。SSL、冻结探针和 VAL/TEST 不做随机增强。分割与 EF 全量 FT 在 TRAIN 使用 `A4_tgc_zoom_speckle`，`per_frame_random=false`：整窗一致的变换参数/噪声模式，几何变换与真实目标 mask 对齐。

| A4 项 | 触发概率 | 参数 |
| --- | ---: | --- |
| TGC | 0.4 | .75–1.35 |
| gamma / 对比度 | 0.5 | gamma .75–1.35，contrast .85–1.20 |
| 亮度 | 0.3 | 幅度 .08 |
| zoom | 0.3 | .92–1.12；对应 mask 同几何 |
| blur | 0.2 | 实现见 `augment/ultrasound.py` 与 `echo_aug_validation/augment_recipes.py` |
| speckle | 0.4 | sigma .03–.10 |
| acoustic shadow | 0 | 禁用 |

无默认水平翻转、大旋转、CutMix、弹性变形。增强适配 `img_size=112`、`preserve_dtype=false`，输出保持浮点；改变增广属于训练配方实验，不应悄悄与架构修改绑定。

## 4. 模型、初始化与监督读出

### 4.1 SSL 编码与递归

| 模块 | 实际参数与行为 |
| --- | --- |
| 局部输入 | 16连续帧/clip，RGB形状的重复灰度，无重叠；Conv3D kernel/stride `(2,8,8)`，tubelet2，网格 `8×14×14`，1568时空token/clip |
| encoder | ViT-S，384维、12层、6头，MLP ratio 4，LayerNorm eps `1e-6`，平坦一维固定 sinusoid；独立 q/v bias、k bias 为0，drop path=0 |
| 状态 | `global`，一个 `[B,1,384]` 向量；每独立窗重置。当前局部 encoder 输出经 token 侧 cross block 读上一clip状态，第一clip没有上一状态 |
| 写入 | `fused`，当前已融合的有效可见token做均值；RVM-style 核一层 `CrossBlock`、6头，向量门控，不是标准GRUCell。对摘要 `x`、旧状态 `s` 算 `z=σ(Wzx·x+Wzs·s)`、`r=σ(Wrx·x+Wrs·s)`，候选为 `LayerNorm(CrossBlock(x,r*s))`，新状态为 `(1-z)*s+z*candidate`；初始更新从零状态起 |
| 近期特征 | 最近最多4个clip/64帧的输出；EF读近期空间池化序列，分割读指定帧的密集网格；不追加独立的历史状态预测 token（`append_boundary=false`） |
| 帧级读出 | `final`，`frame_readout=repeat`，每个tubelet的两帧共享同一个密集特征，不使用学习展开、帧query或独立单帧分支 |
| MAE decoder | 384→192无 bias；补 mask token，加 decoder 位置编码，按配置融合上一状态；4层、3头、MLP ratio 4，恢复全部1568位置，每token回归 `2×8×8×3=384` 像素值 |
| 未启用 | spatial/dual状态、低秩候选、额外正交/频域损失、ROI mask、对比学习、独立时序分割头、额外历史前缀 |

每窗片段之间按时间推进状态，clip 内 ViT 双向注意力；窗口训练的递归状态与反向图不在 clip 间截断，也不跨视频泄漏。最近4个clip是读出上下文容量；不要把冻结探针的磁盘特征缓存与模型内部近期特征混淆，也不要把当前 W64/H0 实验说成已实证任意长流式性能。

初始化权重 `ckpt/mae/videomae_vit_s.pth`；两个独立 SSL 运行均记录加载216个张量、23,290,560参数、encoder 必需键无缺失。patch embedding 的空间卷积核由16→8用 trilinear 重采样（时间长度保持2，`align_corners=false`）；原重建像素头输出1536，与当前384不匹配，权重/bias不迁移。形状匹配的共享 decoder 层继续加载；RVM/融合等新增结构按本地模型初始化。不是把旧 patch16 B0 接着训，也不是把官方 EchoCardMAE 权重当自己的 SSL 初始化。

### 4.2 各任务头与损失

| 阶段 | 读出及训练范围 | 目标 |
| --- | --- | --- |
| SSL | 只将可见 token 送入 encoder，沿整个真实窗重建；最多64帧，H0时等于全部真实clip | `tube` 名义 mask 0.9；同窗沿各时步/clip复用空间选位。patch8 每tubelet保留19/196位置，即每clip152可见、1416遮挡。对已输入标准化的像素做逐tubelet-patch均值/总体方差标准化（`eps=1e-6`），先对每个patch的384维残差做MSE，再对每个窗口的遮挡token求均值，训练 active-clip 路径等权平均窗口。没有未遮挡token辅助损失 |
| 分割冻结线性探针 | 冻结主干并提取无掩码指定帧的 `[196,384]` 特征；每patch `Linear(384,2)`，双线性插值到112×112、`align_corners=false`；770可训参数 | 像素 CE + 前景 soft Dice loss，Dice平滑 `1e-6`；不是下行FT的双类Dice |
| 分割全量FT | 无mask，指定帧 `[196,384]`→384→192无bias；新可学习二维sin/cos初始化位置；4层3头decoder、MLP ratio4、LN eps跟SSL decoder；每patch输出128 logits（8×8×2），重排到 `[B,2,112,112]`，不是对 coarse logits 做插值 | `1-(2∑p*y+1e-5)/(∑p+∑y+1e-5)`，先在每个样本/类按空间累积，再对前景、背景和batch等权平均；无额外 CE。encoder、RVM与任务头参与梯度，不缓存固定特征冒充FT |
| EF 冻结线性探针 | 冻结主干，最近64帧空间池化后时间均值，`Linear(384,1)`；385可训参数 | `SmoothL1(z, EF/100)`，默认 beta=1；评估以百分数输出计算 MAE，不把训练 loss 当 MAE |
| EF 全量FT | 最终特征空间均值得 `[B,64,384]`，经 `384→64` 投影 + 固定时间sinusoid + LN + 标量score；按时间softmax加权，`64→64→1` GELU MLP，末层零权重、bias=.556；不拼 state-only token、不做 sigmoid 或 clamp | `L1(100*z, EF)`，单位pp，和报告MAE一致；初始预测55.6%，不是训练后恒等于均值 |

分割任务头迁移 SSL 的 encoder-to-decoder 投影、四层 decoder blocks 和末端 norm，实际51个共享张量；将独立 q/v bias 合成 `[q,0,v]`，严格 shape/key 检查。新像素分类器 Xavier uniform、bias 0，位置重建为新的二维可学习位置，不沿用视频位置，不迁移重建像素头。任务模型总参数含挂在模型上的不活跃 SSL decoder 等分支，因此总数不等于任务有梯度参数：SSL **29,359,296**；恢复分割 FT **31,275,200 / 28,680,320**（总/观测到梯度）；EF FT **29,388,418 / 26,793,474**。

当前 engine 对可训参数使用同一 AdamW 参数组，无 layer-wise LR decay、无按层冻结阶段；其余 AdamW 选项走运行环境默认（eps `1e-8`）。调度以 optimizer update 为步，梯度累积按实际样本数加权，尾批保留而非 drop last。SSL 157次更新/轮，总计62800或251200；分割对照均254次更新/检查；EF 233次/轮。保存 `last` 用于每轮恢复，固定快照周期25轮，`keep_snapshots=0` 下只留明确钉住的SSL快照（400：0/100/200/400；1600另留800/1200/1600）、best/final及恢复状态。训练记录 TensorBoard、CSV、JSON；TEST 先校验 VAL 选中权重指纹，再作无训练评估。不能根据 TEST 换权重。

**运行参数不等于训练参数。** 单阶段自动探测安全吞吐，候选 micro-batch `[1,2,4,8,16,32,64]`、workers `[0,2,4,8]`、线程 `[1,2,4]`、梯度检查点开/关。基准配置 prefetch2，探测预热2个更新、测6个、超时240秒，显存余量阈值0.1及0.5GiB；心跳15秒、loader超时180秒；冻结缓存预算28GiB、最低磁盘余量3GiB。冻结特征可缓存，已完成缓存可清，绝不清权重。实际执行环境 Python3.10.20 / Torch2.5.1+cu124 / CUDA12.4。探测不自动调LR、不改有效batch；实际配置以 `runtime.json:selected` 为准，不看 YAML 的默认 micro-batch=4。

覆盖 FT 每检查平均229秒训练+324秒验证；长耗时主要由49次更新周期和共同VAL的23648次窗口预测叠加而来。以后若为提速改固定VAL位置数，必须让候选和对照同协议验证，保留现有全位置评估作为最终复核，不应把两套速度和分数混用。

**官方锚点的差异。** 原生112单帧、2D patch8；本地 ViTSeg2D 移植，384维12层6头encoder、192维4层3头decoder，2类像素输出，无递归与缓存。发布权重加载214张量，允许缺失的正弦位置及不匹配的2D patch卷积权重/任务分类头按本地官方路径初始化。使用 `mean=(.1257,.1271,.1292)`、`std=(.1951,.1957,.1974)`；训练时归一化零值 pad12 后随机裁回112，mask同步；验证/测试不随机裁切。与主线使用同样的双类 soft Dice 目标，但训练增强、精度、批量和选择规则不同。它是复用发布权重的本地参照，不是完整复现作者预训练，也不是隔离时序架构的消融。

## 6. 实测性能与读法

### 6.1 分割

统一硬预测 `argmax`。患者平均Dice：先按同一真帧平均各位置Dice，再患者内平均真帧，最后等权平均患者。全局Dice：每个真帧先平均各位置的交集/预测面积/GT面积，再跨帧累加计数，算 `2Σ交集/(Σ预测+ΣGT)`。后者对大前景贡献更高。多位置不会变成多个独立病例，**也没有先融合 mask 再算 Dice**。边界距离用原生像素，ASSD/HD95只在有效边界上算，同时记录失败；不写成mm。

### 6.3 自监督诊断、表征及效率

- 独立400 / 1600轮末轮训练重建loss：`.343421 / .295723`；64病例已见人口重建诊断 `.347892 / .297009`。这是标准化像素MSE，不是百分比、不是独立 VAL、也不参与SSL选权重。
- 同一1600轮轨迹第400→800→1600轮，重建诊断 `.349573→.324794→.297009`，但冻结EF MAE `5.1143→5.5306→5.5605 pp`，冻结患者Dice `88.1866→87.3290→86.5950%`。固定探针读出变差，不能由此断言医学信息永久丢失。独立400与1600的FT也没有稳定的双任务长训收益，故开发默认400轮，不机械追加1200轮。
- VAL 128例384维描述符诊断：独立400实验 epoch0→400 有效秩 `13.31→25.49`，最大主成分占比 `30.44%→22.86%`；独立1600终点 `67.73 / 9.52%`。秩不是解剖或任务能力，不能拿高秩抵消探针变差。单样本 descriptor 提取含传输与CPU物化的p50约33 ms，不含解码/采集、不等同于端到端临床FPS。
- 恢复分割FT峰值已分配约18.81 GiB、峰值reserved约23.03 GiB；完整VAL及TEST评估墙钟分别386.54、359.96秒，锚点完整TEST约30.14秒，1600源EF TEST约32.54秒。递归模型和单帧锚点有不同输入和观察数，这些不是同预算延时对照。

## 7. 已验证的避坑项与证据边界

| 问题 | 我们确知什么 | 后续默认做法 |
| --- | --- | --- |
| **把完整 W64×16目标位置资格当作可用GT门槛** | 旧条件是 `f>=63` 且 `f+16<=N`。8108/14920真实训练帧，实际只用54.34%，丢6812帧；不仅是短视频，长视频靠首尾的标签也会丢。同400源及共同VAL下，恢复监督有实际改善，且完整TEST已接近锚点。新边界上下文、抽样顺序和最终更新量也变了，不把全部改善纯归因于样本数量 | 继续保留 L16、W64上限；分割允许16/32/48/64变长与明确首帧补齐，按真实标注计覆盖。**不是禁止64帧，不是所有任务改成任意长度** |
| **patch16 与 patch8 混用** | `112/16=7`，49空间token；`112/8=14`，196空间token。patch16确实把网格变粗、遮挡下只保留4/49空间位置（32时空token/clip）；patch8保留19/196（152时空token/clip）。历史 B0 patch16 / 更长前缀等旧配方的400轮冻结患者Dice80.2746%，独立patch8为88.6265%；但空间网格、历史/日程、初始化路径等同时不同。不能把全部差值归因于 patch8，未做单因素复训 | **固定 native112/patch8**，检查 patch embed、token grid、dense head 输出同源。除非要研究空间粒度，不把patch16偷偷作为加速或省显存替代品 |
| **指标与人口混比** | 恢复版同一TEST预测全局93.0135%/患者92.4633%，差0.5502 pp只来自聚合定义。原1600和锚点匹配后只差全局0.2157 pp。旧子集不等于完整TEST | 同split/同病例/同真帧，双报Dice；记录目标位置、可用未来、观察数和聚合，不用更好看的口径冒充提升 |
| **用重建loss替代迁移能力** | 同一轨迹重建改善而冻结探针退步；1600相比独立400没有清晰双任务FT收益 | 开发先复用400权重；评价看冻结读出与VAL FT；有明确收益再决定长训，不凭loss追加预算 |
| **头、损失和选择协议变了仍归因主干** | 冻结分割 CE+前景Dice 与全量分割双类Dice不同；EF探针SmoothL1与FT百分数L1不同。历史patch16读出校准没有单独消除分割差距；不能说decoder、L1、初始化任一项已单独验证优越 | 模型结构实验先保持头、loss、初值与选择不变；优化配方实验才有计划地改这些项。记录加载键、有效梯度和最佳epoch |
| **没测TEST或把不同权重的数字拼接** | VAL和TEST、400/1600、原/恢复监督对应不同模型或人口。现有TEST已核验绑定的最佳权重，但400源EF TEST和官方EF锚点仍空缺 | 保持明确模型身份；新增结果按VAL冻结方案后一次性TEST；不为补齐表格重跑可复用的预训练 |

尚未排除：架构本身、LR/WD、掩码率、ROI、对比目标、对齐后真正的官方EF差异及跨种子稳定性。它们不是目前接近93%分割所必需的前置改动，也不是证明无效。原有中值滤波开关资料缺完整配置和独立种子，保留历史观察，不升级成正式消融结论。

## 8. 后续开发合同

**固定项。** 同一份数据/标签清单与样本指纹，native112、patch8、L16、W64/H0、恢复分割覆盖及其边界规则、EF单窗、同一套指标与VAL锁权重方式。保留递归向量状态和有界近期缓存作为设计前提，不要求重新证明它们必要才开始改进。每次记录可训练参数、有效batch、更新次数、观察帧数、墙钟和显存峰值。

**调参线。** 复用同一个400轮 SSL checkpoint，只在VAL对照。先做有决策价值的小范围试验，例如固定其余设置，仅比较分割或EF的 LR/调度；改善看对应任务的VAL主指标及边界/误差分布，未改善即保留现配方，若只有训练loss更好不能晋级。不要把加大有效batch、延长轮次和换模型放在同一对照里。若改采样或早停，说明比较的是同等更新预算还是各自完整收敛，不能把两者混称。

**架构线。** 基线配置和任务头固定，一次改一个可说明的机制，例如目标帧身份读出或跨clip信息进入位置；声明改动是否必须重新SSL。兼容的读出改动先复用现有checkpoint验证，不能兼容时再安排匹配的400轮开发预算。候选进步需反映在真实任务上，若一项提升另一项退步，如实记录，不靠多测窗口或改人口遮盖。只有具体设计决定需要时才追加必要对照。

**何时声称超越。** 分割优先在同病例、同标注和预先声明的输入/聚合协议下对照锚点，双报Dice、边界和失败率；EF先补同协议锚点或明确只声称超越自己的基线。模型选择回到VAL，不以已见TEST结果反复改候选；进入论文确认时控制训练种子、暴露协议与评估预算，报告合理的不确定性和成本。两任务不会因同一MAE就自动都提升。本报告不启动新实验或为追分授权扩预算。
