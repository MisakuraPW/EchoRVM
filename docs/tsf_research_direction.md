# 心超时域、空域、频域一体化：研究切入点

日期：2026-09-16。本文是研究建议，不是已验证的新模型，不修改当前训练实现。

## 1. 核心判断

推荐将主线定义为：**利用不同空间尺度的时序可预测性，学习对心超下游任务有用的结构与运动表征。**

这里的一体化不是三个输入模态，也不要求三个编码器：

- 空间回答“结构在哪里”。
- 空间频率/小波尺度回答“结构由什么尺度、方向的变化构成”。
- 时间回答“这些结构如何演变，哪些信息需要跨片段保留”。

频率变换本身通常没有带来新的观测信息。价值应来自学习偏置、不同误差的权重、掩码任务难度或记忆更新机制，而不是“多一个域就多一份信息”。本轮不主张任何首次性，也不凭调研中“未找到”来认定研究空白。

## 2. 对原调研的核对与修正

### 值得保留的部分

- 共用编码器、频率先从监督目标进入，是低成本验证入口。Scale-MAE 的低/高频重建与 WaMIM 的多级小波目标提供了相关先例，但不是心超效果保证。[Scale-MAE](https://openaccess.thecvf.com/content/ICCV2023/html/Reed_Scale-MAE_A_Scale-Aware_Masked_Autoencoder_for_Multiscale_Geospatial_Representation_Learning_ICCV_2023_paper.html)、[WaMIM](https://arxiv.org/abs/2503.00782)
- Alliance 作者摘要确实描述了渐进频率解码、振幅/相位相关融合和频率感知 token。可以借鉴设计思想，但其遥感谱维不能当成心超时间轴直接替换；本次未审计其完整代码。[Alliance 作者摘要](https://pubmed.ncbi.nlm.nih.gov/41336157/)
- 时间信息可能帮助区分任务相关纹理与成像扰动，但这只是可检验假设，不能预先假定两者可被完美分离。

### 不能直接照搬的部分

1. **互斥掩码不等于防复制。** 同一空间位置在当前帧隐藏、邻帧可见，恰好提供复制线索。跨近邻帧共享 tube mask 通常更直接地阻止同位置复制，但运动仍可能把内容带到别处。互补掩码可用于其他任务设计，不能把它自动称为防泄漏。当前 TemporalMAE 的 tube 路径跨片段共享 spatial_order；首次频率实验应保留，别同时改掩码。
2. **散斑不全是无用噪声。** 它与组织散射和运动相关，也是运动跟踪的信息来源；探头几何和空间变化的点扩散函数还会影响其去相关。不能把“跨帧一致”定义成解剖、“不一致”定义成噪声，也不能把所有高频抹掉。[心超运动跟踪原始研究](https://www.creatis.insa-lyon.fr/~bernard/publis/ultrasonics_2010_touil.pdf)
3. **固定网格 token 不是被跟踪的同一组织。** latent 化没有自动解决位置对应；对固定 token 的时间 FFT 或跨帧一致性约束仍可能混合组织运动、探头运动和亮度变化。
4. **只拟合频谱幅值可能丢失定位。** 全局图像的平移可以改变 Fourier 相位而保持幅值，单靠幅值目标不够约束边界位置。对分割更适合局部、有符号的小波系数或保留空间布局的带通图像。
5. **别把普通频率 MSE 当新信息。** 若 F 是酉变换，使用完整系数且与空间损失支持域一致，则 ||F(pred)-F(target)||² = ||pred-target||²。完整正交小波系数同理。真正的差异来自分带重加权、不同尺度目标、稀疏选择、非二次损失或网络机制；一旦只在部分像素计损失，上述完整域等价条件不再直接成立。
6. **不是超声载频建模。** EchoNet 现有输入是处理后的 B-mode 图像，图像 FFT 不是原始 RF/IQ 频谱；不能把 cycles/pixel 解释为 MHz，也不能仅靠变换恢复丢失的声学相位。
7. 原文的 8–16 GPU 规划不符合当前单卡4090实验条件；当前路线优先复用一个编码器，目标变换在线计算，不新增完整频率数据缓存。

## 3. 三种切入方式

| 切入点 | 改动 | 能回答的问题 | 建议 |
|---|---|---|---|
| 多尺度重建目标 | 原 MAE 加局部小波/带通目标，主干不变 | 更合理的重建任务能否改善表征？ | 作为简单对照 |
| 频率条件化的时序记忆 | 用可见局部频率信息影响空间记忆的写入/读取，共享编码器 | 不同尺度是否需要不同时间依赖？ | 推荐主线 |
| 显式时频建模 | 帧/短片段轨迹上的 FFT/STFT 或多时间尺度算子 | 周期和动态带宽是否带来额外收益？ | 等时间采样口径完备再做 |

“一个空间频率变换 + 时间递归 + 空间布局”已经对应时、空、频，不必为了字面完整性立即添加时间 FFT 或 3D FFT。

## 4. 推荐的完整设想

暂称“空间尺度条件化的时序记忆 MAE”，名称不是已发表方法。

```text
64帧灰度视频，保持现有输入与16帧局部编码协议
                 |
        同一套时空掩码
                 |
     共享局部 VideoMAE 编码器
                 |
         带空间位置的可见 tokens
                 |
可见 patch 局部小波描述 -> 条件化记忆读写 -> 融合后的 tokens
                 |                          |
          跨片段记忆状态             共享 MAE decoder
                                            |
                                  像素 + 多尺度重建目标
```

### 4.1 空频表示

优先选 patch 内小波作为第一种工具，保留低频近似和有符号方向细节。当前112像素、8像素patch的配置下，可以先做1–2层局部分解。层数、方向和频带都是信号处理尺度，不是器官类别。

相较全帧幅值 FFT，这样容易保持与现有 patch 的一一对应，降低引入隐藏像素旁路的风险。代价是局部8像素patch描述不了整腔室的空间尺度，粗解剖布局仍依赖编码器和空间记忆；不要把patch内低频称为全心脏形状。多层全帧小波可作为后续方案，但需重新处理感受野、边界和掩码对应。

选择 Haar 一类短支撑变换可先控制成本；小波选型本身不是创新结论。DWT 的移位敏感性、patch边界效应与resize引入的频谱变化必须检查。不要把对频带编号的硬编码当成学到解剖。

### 4.2 频率条件化的记忆

现有 models/temporal_mae.py 的 _pool、memory、feature_fusion 和 memory_fusion 可以复用。优先基于具有空间状态的实现开展，不是因为 hier_spatial 已被证明最好，而是它保留了空间布局，适合测试此假设。

对片段 k 的可见 tokens Z_k，计算局部尺度描述 q_k，再用共享轻量投影形成条件化读写：

    S_k = R(S_(k-1), Z_k; q_k, position, valid_mask)
    Z'_k = Read(Z_k, S_(k-1); q_k, position)

频率描述可采用按子带归一化的能量/有符号统计，但真正的系数目标应保留更丰富的信息。只把能量用于门控，不能据此声称已经完成精确频率表示。

第一版可按粗尺度与细节分组组织状态，共享 RVM 更新权重，通过尺度标识和输入决定不同读写强度。保持总状态 token 数和隐藏维度尽量匹配对照，不直接把每种频带都复制一整个 RVM。组间允许信息交互，输出仍是同一套任务特征，不拼接三个专业编码器的预测。

**不规定“低频必须慢更新，高频必须快更新”。** 高频边界可能长期稳定可跟踪，低频亮度也可能快速变化。让模型学习条件化更新；门控曲线只是诊断，不能单独证明解剖/噪声解耦。

这才是三个方面之间的具体联系：空间位置决定在哪里读写，尺度描述决定当前内容的特性，时间记忆决定哪些历史对当前重建与下游读出有帮助。可学习门控不等同于已校准的物理时间频谱。

### 4.3 自监督目标

保持原 masked pixel loss，增加固定的分带目标：

    L = L_masked_pixel + lambda * sum_b w_b * L_masked_wavelet_b

也可从现有 decoder 的像素预测计算局部小波损失，先不增加 decoder 容量。按尺度标准化并使用固定子带权重或稳健L1，使目标不是完整正交L2的简单重复。训练集统计、数值下限和权重需要记录；不能由当前预测误差随意降低困难频带的权重，否则门控可能通过忽略目标获利。

lambda 不照抄报告的0.25。先在固定小批次检查各项梯度量级与稳定性，再锁定一个训练配方；不要依赖反复扫验证集挑权重。首次不同时加未来latent、周期、一致性、对比等多个新损失。

## 5. 必须防止的旁路与伪约束

- **完整图像的小波/FFT只允许作为目标或明确的teacher目标。** 如果编码器看到完整图的频率描述，即使原图patch被mask，隐藏答案仍可能进入学生。
- 第一版的频率条件只由完整可见tubelet内部的局部patch计算，不先对整帧卷积再选可见位置。后者滤波支持域可能跨过mask边界。
- 生成目标前使用与输入一致的几何坐标。随机zoom后直接复用zoom前系数会错位；几何变换和小波变换不能默认可交换。
- 沿用增强后的未mask目标是一种重建协议；若目标改成不加speckle的另一个视图，则变成去噪协议，需要独立对照，不能同时偷换目标。
- A4里的speckle、blur、gamma都会影响频率。首次保持增强一致，另做小规模扰动诊断；不要简单强制所有增强前后高频特征完全相同。
- 不把跨帧特征一律拉近。相邻帧有真实收缩舒张变化，过强一致性会学出静态表示。未来若加入teacher一致性，需要停止梯度、抗塌缩机制和合理对应关系。
- 记忆只接收允许的历史和可见信息，不能先从未mask视频建立完整历史再声称masked自监督。局部16帧编码可双向，跨片段更新因果；这不等于全模型逐帧因果。

## 6. 显式时间频率为什么排后

当前64帧拆4段，state_trajectory只有4个片段状态。直接FFT这4点容易把状态初始化、平均池化和窗口重置当成“周期结构”。若研究显式时频，应保留更密集的frame/tubelet特征，核对FPS、stride和有效时长。

例如仅作算术示例：50FPS下64帧约1.28秒，DFT频率栅格间隔约50/64=0.78125Hz。零填充可以让谱曲线更密，不增加真实观测时长和区分相近周期的能力。当前 utils/temporal_data.py 输出frame_indices和有效帧，但没有提供FPS字段，需先补元数据而不是猜帧率。缓存NPY不必重生成，可加来自原始视频的元数据旁表。

固定位置轨迹依旧不是组织跟踪。时间功率谱还会丢失相位/次序信息，心率相近也不代表EF相近。Periodic-MAE针对面部rPPG的周期与频带约束是参考，不代表可直接作为心超功能标签。[Periodic-MAE](https://arxiv.org/abs/2506.21855)

bioFAME说明频率算子与latent masking能构成另一种有效预训练任务，但不能直接搬进当前严格visible-only MAE并声称掩码难度未变。[bioFAME](https://arxiv.org/abs/2309.05927)

未来若显式做时间频率，先从分离的空间小波与时间分析入手，不把Hz与cycles/pixel直接加成3D球形半径。没有可靠spacing时只声明像素归一化尺度，不宣称物理解剖尺度不变性。

## 7. 最小实验安排

遵循“先看完整设想有没有收益，再拆原因”，不一次展开十几个频域消融。

第一步只比较 A 与 C：

| 组别 | 模型 | 用途 |
|---|---|---|
| A | 固定的当前空间记忆MAE、原像素目标 | 结构基准 |
| C | 同一骨干、频率条件化记忆、多尺度目标 | 完整设想 |

先定100轮筛选预算，两个实验从同一预训练初始化开始，保持视频长度、局部窗口、掩码率、采样、增强、有效batch、优化器、LR日程、病例与随机种子协议一致。不同模块初始化会消耗不同随机数，数据/掩码应使用独立受控随机流；同一个整数seed本身不等于逐样本严格配对。匹配状态容量并记录新增参数/FLOPs/实际训练耗时。

与旧400轮轨迹比较时，不能把新100轮cosine日程当成旧日程前100轮。要么按旧400轮日程在100轮截断，要么A/C都以同一个100轮日程重跑。仅当旧A数据和协议完全可核对且所需快照仍存在时才直接复用，尤其新Dice口径不能用旧Dice替代。

若C有明确收益，补 B：同一个A模型只加相同多尺度目标，不加条件化记忆。C优于B才支持记忆机制有额外价值。随后再考虑去掉记忆、固定门控或参数量匹配的非频率门控，区分频率条件、额外容量和一般门控收益。C若不改善，优先定位多尺度目标/读出/数值问题，不先扩大模型或宣称训练轮数不够。

这不是最终论文消融表；它是最低成本的决策顺序。单seed短训的阴性/阳性结果都只能指导继续投入，不能作最终定论。

## 8. 评价随研究问题调整

沿用上一轮快速EF筛选，但此方向首次完整判断必须增加一个便宜的空间读出，否则可能漏掉真正的空间收益：

- 0/100节点：固定冻结EF读出，保留状态EF作诊断；不重跑全量微调。
- 100节点：A/C各做一次冻结分割探针。采用已修正的历史上下文口径，报告逐患者Dice及可选边界指标，不用旧重置点Dice冒充记忆效果。
- 无需重新预训练：在固定验证子集上，用同一个已拟合探针对轻度speckle/gamma/压缩扰动测试性能下降，不只测特征相似度。鲁棒但任务能力差的常数表示不算成功。
- 只有明确收益后再扩大病例、多seed、CAMUS迁移和最终全量微调。合成扰动鲁棒性不能替代真实跨设备验证；CAMUS标签与视图口径也需单独匹配。

可将结果分成“功能收益”“空间收益”“稳健性收益”，不先任意加权成总分。若仅空间改善，应如实收窄主张；若只是重建更漂亮或门控更活跃，不算下游表征成功。

## 9. 复用边界与下一步

可复用：models/temporal_mae.py 的局部VideoMAE、mask、递归展开、空间池化和融合；tools/evaluate_temporal_screen.py 的冻结EF与独立Dice；既有自动调参、断点续训、结果/权重分离工程。

待实现：patch局部频率目标、visible-only频率条件、状态条件化读写、损失尺度日志及泄漏测试。小波实现应使用可核查的成熟工具或明确滤波器，并做重构与能量等价测试。无需重新缓存三通道频率视频，不默认上第二个大编码器，也不改已完成实验。

最终应回答的不是“加频域有没有让模型更复杂”，而是：**在相同观测和训练预算下，以空间尺度为条件组织历史信息，是否比通用记忆更有效地支持心超功能与结构任务？**
