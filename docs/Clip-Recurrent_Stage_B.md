# Stage B: four variable clips, one 64-frame EF window

This supervised pilot asks whether a causal, content-dependent boundary rule improves EF over non-adaptive variable boundaries. It does not retrain SSL or segmentation. It starts at the already evaluated A-R SSL epoch 400 (all splits unlabeled, transductive), preserves native112, patch8, tubelet2, the original mid-block-6 read and global recurrent state, and reuses the calibrated TemporalEFReadout.

All clips are real, consecutive and non-overlapping. Four clips exactly cover W64, with lengths 8 to 32 in increments of 4. The observer's stop decision uses framewise low-resolution features, a GRU updated on each newly available four-frame group, detached previous-clip S, and the remaining frame/clip budget. It cannot use pixels after the proposed boundary or any labels. The final encoder is bidirectional within each already collected clip, so output has an 8 to 32 frame boundary delay, not zero-latency per-frame causality. Native L16 processing is unchanged; other lengths use the existing flatten-order sinusoid formula. Head positions remain relative to the original W64 input. Each segment is encoded once, grouped by length for batching. Each video starts with new state and its own bounded recent descriptor buffer.

- B1: 20 supervised EF epochs using uniformly sampled feasible four-clip compositions. Select the original warmup checkpoint by its random-boundary VAL score, also report fixed L16 VAL with the same weights.
- B_uniform and B_observed: independently initialize optimizer state from the same B1 VAL-selected weights. The non-adaptive arm continues uniform sampling; the adaptive arm starts at the same uniform hazard and learns a residual from the observer. It samples with fixed index-keyed random numbers at VAL/TEST, not label-derived boundaries. Training uses the same RNG policy keyed by split, sample and epoch on both arms.
- Both arms have at most 40 equally budgeted epochs with patience 10, min epochs 10, and original min_delta 1e-4 pp. The original A-R EF FT recipe is inherited: W64/H0, same official split and frame-consistent training augmentation, AdamW LR 1e-5, WD 1e-4, effective batch 32, L1 EF in percentage points. Runtime tuning changes only execution grouping/workers/recomputation. B-observed adds REINFORCE on free decisions with detached advantage clipped to +/-20 pp, an action-independent state-value baseline from detached observation features, and an entropy bonus. The negative per-window EF error supplies the reward; the original EF loss backpropagates through the actually encoded path. Forced boundaries take no actor/critic credit.

The queue first measures real throughput of each policy at the full effective batch. It keeps B1 at 20 epochs and, if needed, reduces both arms to the same epoch cap before training begins, targeting no more than 8 GPU hours including reserve. If the measured budget cannot fit two 10-epoch branches after B1, it refuses to launch rather than silently changing the scientific budget. No feature cache is used: changing boundaries changes the encoder and recurrent trajectory. The results and checkpoint trees stay separate; epoch-boundary recovery and a 5 GiB checkpoint write floor are enforced.

Use `python -u tools/run_patch8_stage_b.py plan`, then `smoke`, then `run`. Planning and smoke do not access TEST. The run evaluates all three formal endpoints once on TEST after locking selected weights on VAL. Main comparison: paired patient EF MAE with RMSE, bias and strata; about 0.10 pp VAL gain is a practical threshold for further design work, not proof of generalization. Also report actual cost, bounded clip lengths, actor gradients and entropy, simple observed-motion correlation, and latency. Original fixed-L16 full FT is descriptive because its budget differs. No automatic follow-up training or selection using TEST.
