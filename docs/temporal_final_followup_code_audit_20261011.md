# 后续时域实验代码复核与旧实现对照

日期：2026-10-11。范围：当前 `P/ft/ef` 之后尚未执行的任务。
本文件是代码审计，不是科研结果总结，不关闭 Q1-Q3，不修改协作 Excel。
当前及已经完成实验保留原代码和结果，不能在运行中直接覆盖服务器代码。

## 1. 结论

核心评价仍然是 EF/分割的冻结读出与全量微调。此次不是新的下游训练算法。
机制与配对设计有新增，但不能用“实验独特”替实现低效开脱。
旧快速筛查与本轮强校准的病例规模、更新次数、分割头和反向传播不同，耗时不应直接相等。
另一方面，新任务 trainer 没有沿用旧通用微调的跨 epoch loader 复用，确实引入了不必要开销。

## 3. 真正新增或实质加强的诊断

| 内容 | 与旧工作不同之处 | 回答什么，不回答什么 |
|---|---|---|
| 可变真实前缀的共同适配 | 各B配置同C100起点、同样本/H/mask计划、相同成功更新数；只重建近期64帧 | 旧状态能否接受缓存外历史的内容梯度；不要求应用启动前已有H128 |
| B2/B3单因素 | 先只改local写入，再只将读取移至基础帧展开之后 | 区分写入反馈与读取位置，不能归因于多训了一轮 |
| B4 candidate rank32 | 只限制归一化candidate，保留原gate和旧state通路 | 检验写入候选瓶颈，不等同于把整个state强制低秩 |
| B5/B6 | factorized与共享参考的全维收缩，在同背景同预算比较 | 区分低秩选择与一般收缩；不证明正交正则的唯一因果作用 |
| 同权重出口读出 | 对C/F的local/base/final分别训练同规格头 | 定位共享训练、融合与帧变换的可读代价，而非把跨checkpoint差异都归给单个模块 |
| 条件R5 | 近似任务表现/互补时，cache+边界state预测下一真实clip的共同C100第9层变化；train-only PCA16 | 测缓存外信息增量；不是生理相位标签，不训练新MAE，不允许未来输入泄漏 |
| 有限B7/B8 | 固定beta0.5或spatial_global17槽，仅按登记证据触发，各最多一次 | 不展开组合网格，不预先宣布组合MAIN成立 |
| 内容与解剖证据 | FP32 real/repeat/swap身份检验、train-fitted像素/解剖线性读出、患者配对 | 防止只看rank/热图；不替代外部测试或多MAE种子 |

其中历史干预、流式和不少表征分析已有旧实现基础；新增的主要是严格配对、机制对照和有界闭合规则。

## 4. 本次发现与修复

### 4.1 冷缓存提特征没有OOM保护

冻结头自动调参只测缓存后的头；因此选出的micro-batch未证明同大小的FP32骨干冷提取能装进GPU。
修复：仅冻结特征提取发生CUDA OOM时，将该提取批次二分重试；头部micro-batch、有效batch、样本顺序不变。
保持FP32、eval、no_grad；单样本仍OOM则明确失败，不伪造特征，也不静默降精度。
缓存结果记录 `extraction_oom_retries`。
GPU不同批量可能产生微小浮点舍入差异；不承诺CUDA逐位等同。CPU模拟OOM验证保持样本和特征精确一致。

### 4.2 persistent_workers设置存在，但跨轮复用不存在

旧新task trainer每轮销毁TRAIN loader，VAL另建，下一轮再启动，spawn放大了启动开销。
修复：每任务复用一个TRAIN和一个VAL loader；更新sampler的epoch/恢复cursor；增强和位置仍由样本/epoch确定。
任务完成或异常退出时显式回收其worker。不是改回不安全fork，也不是改变数据采样。
两组持久worker共存时，冻结特征RAM预算按 `2*workers+1` 分配，不能继续只除以 `workers+1`。

### 4.3 计划要求的位置/P10信息没有写入指标

原 `_aggregate` 保留了总体患者Dice，却丢弃聚合前的目标位置表现。
修复：添加患者Dice P10、各位置的患者等权Dice、位置均值及极差。
主患者Dice算法、best选择和早停条件不变；位置统计仍先聚合源标签帧再聚合患者。
不会因此追加验证前向或重训。

### 4.4 可变历史训练的物理覆盖记录不完整

原适配结果有H计数，但未显式记录处理帧数/按源FPS换算的时间覆盖。
修复：在成功更新后累计样本数、前缀帧数、总输入帧数、近期重建帧数、前缀/输入物理秒数；与last一起恢复。
秒数是各训练抽样的帧数/FPS之和，不是去重后的视频总时长，也不是训练墙钟时间。
